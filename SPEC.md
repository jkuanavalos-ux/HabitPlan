# HabitPlan web simple

La nueva instrucción del propietario reemplaza el plan móvil: una app sencilla para el navegador, sin Expo ni Android Studio.

- Hoy, Objetivos y Horario.
- Hábitos editables con checks por fecha, sin chequear días futuros.
- Objetivos editables, fecha opcional, porcentaje manual o total de Gs cobrados y resultado marcado manualmente.
- Horario por día, bloques editables con días, horarios y color, sin superposiciones.
- Datos originales mantienen nombres, fechas y colores.
- Guardado local y respaldo JSON.
- Español, diseño responsive y tema oscuro azul medianoche.
- Abrir `index.html` directamente o `npm start` para localhost.
- Sin cuentas, servidor de datos, UsageStats, notificaciones, estadísticas complejas ni CRM.
- Cálculos puros en `/src/domain`, tests Jest. Listo para Git y hosting estático.
